# Portal Acadêmico — versão 3

Projeto front-end demonstrativo em HTML, CSS e JavaScript puro.

## Como abrir
1. Extraia a pasta.
2. Abra `portal-senac-v3` no VS Code.
3. Abra `index.html` no navegador ou use a extensão Live Server.

## Acessos de demonstração
- Aluno: `aluno` / `123456`
- Professor: `professor` / `123456`

## O que foi melhorado
- Layout 43/57 mais equilibrado.
- Logo sem caixa branca e com fundo transparente.
- Texto institucional mais curto e hierarquia visual mais limpa.
- Seletor Aluno/Professor com ícones e estado ativo mais claro.
- Títulos, rótulos e placeholders adaptados ao perfil escolhido.
- Inputs mais compactos.
- Botão principal com hover e animação discreta.
- Recuperação de senha em 3 etapas: conta, contato e confirmação de envio.
- Recuperação por e-mail ou SMS com validação local.
- Acessibilidade de teclado, foco visível, modal com foco contido e suporte a `prefers-reduced-motion`.
- Responsividade para desktop, tablet e celular.

> Observação: autenticação e recuperação são demonstrações locais. Um sistema real deve validar credenciais e enviar e-mails/SMS por um backend/API segura.
