# Portal Acadêmico — Login demonstrativo

Projeto front-end em HTML, CSS e JavaScript puro.

## Como abrir

1. Extraia a pasta do ZIP.
2. Abra a pasta `portal-senac-v2` no VS Code.
3. Abra `index.html` no navegador ou use a extensão Live Server.

## Logins de teste

- Aluno: `aluno` / `123456`
- Professor: `professor` / `123456`

## O que funciona

- Alternância entre Aluno e Professor.
- Login separado por perfil e redirecionamento para a página correta.
- Mostrar/ocultar senha.
- Lembrar usuário e perfil no navegador.
- Recuperação de senha por e-mail ou SMS, com validação e tela de confirmação.
- Logout e proteção simples das páginas de aluno/professor.
- Layout responsivo.

## Importante

Este é um projeto demonstrativo de front-end. Usuários e senhas estão no JavaScript para facilitar a apresentação. Em um sistema real, autenticação e recuperação de senha devem acontecer em um servidor seguro com banco de dados e serviço de e-mail/SMS.
